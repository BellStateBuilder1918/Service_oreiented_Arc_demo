# SOA Order Processing (Flask)

Three independent REST services: Customer (5001), Inventory (5002), Order/orchestrator (5003).
See `SOA Case Study Online Shopping Order Processing.md` for the design.

## Run

    pip install -r requirements.txt
    run_all.bat        (or run each app.py in its own terminal)

Import `SOA_Order_Processing.postman_collection.json` into Postman to demo.
